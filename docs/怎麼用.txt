PN Anywhere　Windows 版
===============================================

【怎麼開始】

1. 雙擊「PN Anywhere.exe」

   第一次開可能會跳出藍色的「Windows 已保護您的電腦」，
   那是因為這個程式沒有付費的數位簽章，不是有問題。
   點「其他資訊」→「仍要執行」。

2. 看畫面右下角的工作列（時鐘旁邊），
   會出現一顆晶片圖示（單色，會跟著你的主題變黑或變白）。
   找不到就點那個向上的箭頭展開。

3. 右鍵那顆圖示 →「匯入 Price Book…」，
   把你的 Excel 拉進去，選料號是哪一欄、要顯示哪些欄位。

4. 之後隨時按 Shift + Alt + Space 就能查。


【怎麼查】

   Shift+Alt+Space 叫出視窗
   打字            直接找，不用按 Enter
   上下鍵          選
   Enter           看這一筆的完整資料
   左右鍵          同一個料號有好幾列時（階梯報價、不同批號），換一列看
   Esc             從完整資料回清單；在清單再按一次關掉

   摘要或標題旁邊出現「3 筆」，代表這個料號在檔案裡有 3 列，
   畫面上顯示的是最後一列。按左右鍵可以看另外兩列。


【出問題的時候】

■ 雙擊沒反應
   改開「PN Anywhere-診斷版.exe」。它會開一個黑色視窗，
   把每一步印出來，死在哪一行就看得到。
   把那些字拍照或複製起來。

■ 熱鍵沒反應
   右鍵工作列圖示，會有一項「⚠ 熱鍵沒掛上…」，
   點進去會告訴你原因。多半是被別的常駐軟體佔走了。
   這種情況下右鍵圖示 →「查詢」照樣能用，功能一模一樣。

■ 說不上來的怪
   右鍵圖示 →「診斷資訊…」→「複製全部」，把整段貼給對方。
   那份報告裡有系統版本、套件版本、熱鍵狀態、
   載入了哪些檔案幾筆、一次真實查詢的結果，以及最近的錯誤紀錄。


【想調整畫面】

   config\settings.json 裡面幾乎什麼都能改，改完重開程式：

     熱鍵撞到別的軟體    "key": "space" 改成 "f2"、"q" 之類
                          "modifiers": ["alt"] 可填 ctrl / alt / shift / cmd
     字太小 / 視窗太窄    theme 裡的各種 _size、window.width
     清單想列 8 筆        window.list_rows 和 data.result_limit
     每列想多顯示一欄     window.list_fields

   改壞了就把 settings.json 刪掉，重開會自動產生新的。


【搬家 / 備份】

   整個資料夾複製走就好，設定和匯入的資料都在裡面，
   不會寫到系統其他地方，也不需要「安裝」或「解除安裝」。
   不要了就直接刪掉整個資料夾。
