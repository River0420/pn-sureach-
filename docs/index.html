在任何軟體裡按一組熱鍵，直接查料號的價格、庫存、交期。
打字就出結果，不用切視窗、不用開 Excel。

打字的當下就出結果，不用按 Enter

它解決什麼

不用再開 Excel 找

報價單、庫存表、供應商表分散在好幾個檔案裡。這裡用料號把它們串起來，一次看完。

快到沒有等待感

每按一個鍵重算一次，0.94 毫秒。15 萬筆資料跟 100 筆一樣快。

資料不離開你的電腦

不連外網、不上傳、沒有帳號。你的成本價就只在你的硬碟裡。

髒檔案也讀得進來

ERP 吐出來的假 .xls、Big5 編碼、前面卡兩列公司抬頭 —— 都自己認得出來。

重複料號會講

同一個料號有階梯報價、不同批號時，畫面會標「3 筆」，←→ 換著看，不會讓你抄到錯的價。

不佔用你的畫面

常駐在工作列／選單列，不進 Dock、不搶前景。查完 esc 就消失。

怎麼開始

  1. 下載、解壓、打開。Windows 雙擊 exe；macOS 拖進「應用程式」後右鍵 →「打開」。
  2. 匯入你的 Excel。點工作列／選單列的晶片圖示 →「匯入 Price Book」，最多三個檔案，選好要用哪一欄當料號。
  3. 按 ShiftAltSpace。打字就開始找。↑↓ 選、Enter 看完整資料、esc 關掉。
第一次開會被系統擋下來，這是正常的。
Windows 會跳「Windows 已保護您的電腦」→ 點「其他資訊」→「仍要執行」。
macOS 會說「無法打開」→ 在 App 上按右鍵 →「打開」。
兩個都是因為這個程式沒有買數位簽章（Windows 約 US$200／年、Apple US$99／年）， 不是程式有問題。

誠實說明

這個工具只呈現你自己匯入的檔案內容，不修改、不推算、不猜任何數值。 畫面上每一個數字都是從你的儲存格直接搬過來的。

但它終究讀的是你給它的檔案 —— 報價、交期與庫存， 請以貴公司正式系統及供應商回覆為準。
